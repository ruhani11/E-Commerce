# 🛒 Full-Stack E-Commerce Web Application

A fully responsive and dynamic e-commerce web application built using the MERN stack. The project includes an admin dashboard for managing products and orders, and a backend server with RESTful APIs and authentication.

---

## 🚀 Tech Stack

- **Frontend**: React.js, Vite, HTML5, CSS3, JavaScript, Axios  
- **Backend**: Node.js, Express.js, MongoDB, JWT Authentication  
- **Tools**: Git, GitHub, GitHub Desktop, Postman  

---

## 📁 Project Structure

E-Commerce/ │ ├── admin/ # Frontend (React + Vite) │ ├── public/ │ ├── src/ │ └── package.json │ ├── backend/ # Backend (Node.js + Express) │ ├── routes/ │ ├── controllers/ │ ├── models/ │ └── server.js │ └── README.md


---

## ✨ Features

- 🔐 Admin authentication and route protection
- 📦 Product add/edit/delete functionality
- 📋 Order management system
- 📊 Admin dashboard interface
- 🔍 Search and filter products
- ⚡ API integration with MongoDB
- 📱 Fully responsive UI
